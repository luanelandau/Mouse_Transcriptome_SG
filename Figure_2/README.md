# Figure 2 analysis and source plots

This directory contains the R scripts, input data, and computational source plots used for panels **2a–c and 2e** of Figure 2. Together, these analyses characterize sex-biased gene expression across mouse tissues, compare sex-biased expression in mouse and human submandibular glands, and relate sex-dimorphic saliva proteins to salivary-gland transcriptomes.

The plots generated here were subsequently edited and assembled with experimental images and annotations to produce the final publication figure. The files in this directory therefore preserve the quantitative source plots but may not exactly match the typography, labels, dimensions, or arrangement of the assembled figure.

## Scripts and outputs

### Figure 2a: overlap of mouse sex-biased genes across tissues

Script: `Fig2a_upset_plot.R`

This script reads sex-comparison DESeq2 results for PAR, SM, SL, pancreas, and liver. A gene is considered a sex-differentially expressed gene (sex-DEG) when:

```text
adjusted p-value < 0.05 and |log2 fold change| > 1
```

It constructs a binary tissue-membership table and uses `ComplexUpset` to visualize exclusive intersections containing at least five genes. The script also calculates the genes in every exclusive tissue combination and creates long and compact intersection tables in memory. Their CSV export commands are included but commented out.

Outputs:

```text
Fig2a_ALLglands_upset_SEX.png
Fig2a_ALLglands_upset_SEX.svg
```

### Figure 2b: mouse and human SM volcano plots

Script: `Fig2b_volcano_plot_sex_SM_hum_mouse.R`

This script compares sex-biased expression in mouse and human SM using the corresponding DESeq2 result tables. Genes are classified as up in males, up in females, or not significant using an adjusted p-value threshold of 0.05 and an absolute log2-fold-change threshold of 1. The volcano-plot y-axis shows `-log10(p-value)`, while the dashed horizontal reference line denotes the adjusted-p-value cutoff. Selected genes with especially strong statistical signals are labeled, using species-specific labeling criteria defined in the script.

Output:

```text
Volcano_SexDifferences_Mouse_Human_SM.png
```

### Figure 2c: saliva proteome and gland transcriptome integration

Script: `Fig2c_Sex_analysis_proteome_2.R`

This script integrates sex-differential mouse saliva proteomics with sex-DEGs from PAR, SL, and SM. It:

1. Reads the externally generated saliva differential-proteomics results from `Saliva_mouse_sex_diff.csv`.
2. Retains unambiguous, single-gene protein groups with `Qvalue < 0.05`.
3. Identifies gland transcriptome sex-DEGs using `padj < 0.05` and `|log2FoldChange| > 1`.
4. Joins these results to mean male and female saliva iBAQ values generated by the Figure 1 workflow.
5. Imputes missing mean iBAQ values as zero and transforms abundance as `log10(1 + iBAQ)`.
6. Annotates each saliva protein by whether its gene is a sex-DEG in zero, one, two, or three salivary glands.
7. Produces a male-versus-female abundance plot and a summary bar plot, and prints overlap diagnostics to the R console.

Current outputs:

```text
correlation_of_significant_male_vs_female_proteins_with_contribution_from_each_gland.png
correlation_of_significant_male_vs_female_proteins_with_contribution_from_each_gland.svg
bars_number_of_DEGs_genes_per_gland_in_saliva.png
bars_number_of_DEGs_genes_per_gland_in_saliva.svg
```

The directory also contains earlier versions of these plots with the following filenames:

```text

Fig2c_sex_dimorphic_saliva_proteins_by_gland_transcriptome.svg
```

#### Proteomics input

`Saliva_mouse_sex_diff.csv` is an input from a differential proteomics analysis performed externally by the proteomics analysis provider. It contains female-versus-male protein abundance statistics, including average log2 ratios, p-values, Q-values, UniProt identifiers, and gene assignments. It is not generated by an R script in this directory.

### Figure 2e: expression of sialyltransferase genes in mouse SM

Script: `Fig2e_sialic_acids_plot.R`

This script reads the annotated mouse SM expression master sheet and plots TPM values for five sialyltransferase genes:

```text
St3gal1, St3gal4, St3gal5, St6galnac2, St6galnac1
```

Sample sex is inferred from `Mal` or `Fem` in the sample-column names. The plot combines sex-colored boxplots and jittered values and displays the y-axis from 0 to 200 TPM.

Output:

```text
boxplot_sialic_acids.png
```

The script suppresses boxplot outlier symbols. As noted in the source code, the high `St3gal1` outlier shown as a triangle in the assembled figure was added manually during figure preparation.

## Panels and elements not generated here

The immunofluorescence images and the biochemical blot/lectin-assay components in the assembled figure are experimental images rather than outputs of these R scripts. This directory only generates the quantitative plots described above. Panel lettering, sex-count arrows, legends, selected labels, the 2c inset placement, and the final multi-panel layout were added or adjusted during figure assembly.

## Running the analyses

Run the scripts from the repository root after confirming that each script's `setwd()` path matches the local checkout:

```bash
Rscript Figure_2/Fig2a_upset_plot.R
Rscript Figure_2/Fig2b_volcano_plot_sex_SM_hum_mouse.R
Rscript Figure_2/Fig2c_Sex_analysis_proteome_2.R
Rscript Figure_2/Fig2e_sialic_acids_plot.R
```

Recommended order:

1. Complete the mouse and human DESeq2 analyses.
2. Run the Figure 1 proteome/expression workflow to create `proteome_iBAQ_means_by_gene.csv`.
3. Run the four Figure 2 scripts above.

`Fig2a_upset_plot.R` includes an interactive `View()` call. When running non-interactively with `Rscript`, comment out that line if it causes an error in the local R environment. All scripts contain a user-specific absolute `setwd()` call; replacing it with the path to the local repository is necessary on another computer.

## Interpretation notes

- DESeq2 fold-change direction depends on the contrast used to generate each input table. In the volcano script, positive fold change is labeled as higher in males and negative fold change as higher in females.
- The Figure 2c saliva table reports the comparison as female/male, whereas the plotting script places mean male abundance on the x-axis and mean female abundance on the y-axis.
- Protein groups assigned to multiple genes (semicolon-separated gene symbols) are excluded from the Figure 2c integration to avoid ambiguous transcript–protein mapping.
- The SVG files are suitable for downstream vector editing; PNG files provide raster previews and publication-source exports.
