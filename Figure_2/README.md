# Figure 2 analysis and source plots

This folder contains the scripts, inputs, and computational source plots for Figure 2 panels 2a–c and 2e.

| Panel | Analysis | Script |
|---|---|---|
| 2a | Overlap of mouse sex-biased genes across five tissues | `Fig2a_upset_plot.R` |
| 2b | Mouse and human SM sex-differential-expression volcano plots | `Fig2b_volcano_plot_sex_SM_hum_mouse.R` |
| 2c | Sex-dimorphic saliva proteins and gland transcriptomes | `Fig2c_Sex_analysis_proteome_2.R` |
| 2e | Sex-stratified expression of sialyltransferase genes in mouse SM | `Fig2e_sialic_acids_plot.R` |

The scripts use mouse and human DESeq2 results, annotated mouse expression master sheets, and Figure 1 proteome summaries. `Saliva_mouse_sex_diff.csv` is an external differential-proteomics input and is not generated here. The sialyltransferase plot `boxplot_sialic_acids.png` also contributes to Figure S7.

Run the scripts from the repository root after reviewing their project-specific paths:

```bash
Rscript Figure_2/Fig2a_upset_plot.R
Rscript Figure_2/Fig2b_volcano_plot_sex_SM_hum_mouse.R
Rscript Figure_2/Fig2c_Sex_analysis_proteome_2.R
Rscript Figure_2/Fig2e_sialic_acids_plot.R
```

Experimental images and final panel assembly are not generated by these scripts. PNG and SVG files in this folder are source plots used to prepare the final figure.
