# Figure 1 analysis and source plots

This directory contains the R scripts and source plots used to generate panels **1a–c and 1e** of Figure 1. Panel **1d is not included** because it was produced using a separate workflow.

The scripts generate quantitative source plots from the transcriptomic and proteomic data. The resulting plots were subsequently **manually edited and assembled in Inkscape** to produce the final publication figure. Consequently, the files generated here are source plots and may not be visually identical to the final figure layout in the paper.

## Directory context

The scripts expect this directory structure:

```text
Mouse_Transcriptome_SG/
├── miscelaneous_sheets/
│   ├── human expression/
│   │   ├── PAR_human_mastersheet_TPMs_annotated_with_orthology.csv
│   │   ├── SM_human_mastersheet_TPMs_annotated_with_orthology.csv
│   │   └── SL_human_mastersheet_TPMs_annotated_with_orthology.csv
│   └── mouse_expression/
│       ├── PAR_mastersheet_TPMs_annotated_for_secretion_and_orthology.csv
│       ├── SM_mastersheet_TPMs_annotated_for_secretion_and_orthology.csv
│       └── SL_mastersheet_TPMs_annotated_for_secretion_and_orthology.csv
└── Figure_1/
    ├── Figure1a-b_human_and_mouse_bubbles.R
    ├── Fig1c_barplots_orthology_secreted_genes_human_mouse.R
    ├── Figure1e_proteome_correlation.R
    ├── Saliva_mouse_summary.csv
    └── outputs_proteome_x_expression/
```

Gland abbreviations are:

- `PAR`: parotid gland
- `SM`: submandibular gland
- `SL`: sublingual gland

## Input data

### Transcriptomic data

Panels 1a–c and 1e use the annotated human and/or mouse gland-expression master sheets under `miscelaneous_sheets/`. These tables contain mean transcript abundance in transcripts per million (`Mean_TPM`), secretion annotations, gene identifiers, and orthology annotations.

The human inputs are located in:

```text
miscelaneous_sheets/human expression/
```

The mouse inputs are located in:

```text
miscelaneous_sheets/mouse_expression/
```

### Saliva proteomic data

Panel 1e additionally uses:

```text
Figure_1/Saliva_mouse_summary.csv
```

This proteomic dataset was generated by mass spectrometry of **total mouse saliva**. The proteomic data are also provided in the paper's Supplementary Materials. The Figure 1e script summarizes saliva protein abundance using iBAQ values and compares these measurements with mouse salivary-gland transcript abundance.

## Scripts and outputs

### Figure 1a–b: human and mouse expression bubbles

Script:

```text
Figure1a-b_human_and_mouse_bubbles.R
```

This script selects the top 30 secreted genes by mean TPM for each human and mouse salivary gland. It creates circle-packing plots in which bubble area represents mean TPM and color represents the gene's orthology category.

Primary outputs:

```text
bubbles_mouse_top_human_bottom_3glands.svg
bubbles_mouse_top_human_bottom_3glands.png
bubbles_mouse_row_3glands.png
bubbles_human_row_3glands.png
```

### Figure 1c: expression by orthology category

Script:

```text
Fig1c_barplots_orthology_secreted_genes_human_mouse.R
```

This script groups secreted genes into one-to-one, lineage-specific, and other orthology categories. It calculates each category's contribution to total expression among genes meeting the script's TPM threshold and compares human and mouse glands.

Primary outputs:

```text
percent_total_expression_orthology_TPM10_secreted_combined_horizontal.svg
percent_total_expression_orthology_TPM10_secreted_combined_horizontal.png
```

The filename is retained from the original analysis. The filtering threshold used for a particular analysis should be confirmed from the current script parameters.

### Figure 1e: gland expression versus saliva proteome

Script:

```text
Figure1e_proteome_correlation.R
```

This script:

1. Reads the total mouse-saliva mass-spectrometry results.
2. Calculates mean iBAQ abundance from saliva samples 1–10.
3. Retains unambiguous protein groups with a single gene identifier.
4. Joins the proteomic results to secreted-gene expression data from PAR, SM, and SL.
5. Calculates gland-specific Spearman correlations between log-transformed mean TPM and saliva iBAQ.
6. Generates gland-specific source plots containing a box defined by the top 100 genes by TPM. The top-50 gene selections are used in the Figure 1e workflow.

Outputs are written to:

```text
outputs_proteome_x_expression/
```

Primary plot outputs:

```text
scatter_secreted_TPM_vs_iBAQ_top50_box100_PAR.svg
scatter_secreted_TPM_vs_iBAQ_top50_box100_SM.svg
scatter_secreted_TPM_vs_iBAQ_top50_box100_SL.svg
proteome_vs_expression_scatter_faceted_salivary_green_labeltop50.png
proteome_vs_expression_scatter_top100ONLY_salivary.png
```

Supporting tabular outputs:

```text
proteome_iBAQ_means_by_gene.csv
joined_secreted_proteome_expression_PAR_SL_SM.csv
correlation_secreted_proteome_expression_by_gland.csv
```

The two faceted PNG files were also used in the supplementary-figure workflow.

## Running the analyses

Run the scripts from an R session with the required packages installed. The scripts for panels 1a–c currently set the working directory to the local `Mouse_Transcriptome_SG` directory. The Figure 1e script instead resolves its paths from its own location and can be run from any working directory.

For example:

```bash
Rscript Figure_1/Figure1a-b_human_and_mouse_bubbles.R
Rscript Figure_1/Fig1c_barplots_orthology_secreted_genes_human_mouse.R
Rscript Figure_1/Figure1e_proteome_correlation.R
```

Packages used across the scripts include `dplyr`, `readr`, `stringr`, `ggplot2`, `ggrepel`, `purrr`, `packcircles`, `ggforce`, `patchwork`, and `forcats`.

## Publication-figure preparation

The SVG and PNG files produced by these scripts are computational source plots. After generation, selected plots were manually edited in **Inkscape** to adjust labels, typography, spacing, panel arrangement, and other presentation details for the final paper figure. The scripts and unedited outputs preserve the quantitative analysis; the final assembled artwork should be consulted for the exact published appearance.
